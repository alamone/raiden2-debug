# raiden2-debug
Raiden II Debug Mode

Enables Debug Mode in Raiden II (Japanese).

Dependencies: NASM, Python

How to use:
1. Install NASM (https://www.nasm.us/) and Python (https://apps.microsoft.com/detail/9pnrbtzxmb4z) if you have not already
2. Copy the Raiden 2 (J) rom files "prg0.u0211" and "rom2j.u0212" into the "raiden2j" folder
3. Run "patch.bat"
4. Patched files will be in "raiden2j-modded"

How to use the debug menu (in-game):
- Press 2P Start to enter the SCR debug menu.
- Press 2P Start again to enter the GLOBAL INFORMATION MENU.
- Press 1P Start to exit the current menu.

If you prefer to use a MAME cheat, copy "raiden2j.xml" into the "cheat" folder of your MAME folder.
The MAME cheat also has a stage select.
